# Ma Maison Organisée — première maquette

Application web progressive (PWA) en français, avec palette rose poudré, lilas clair, crème et bleu ciel.

## Ce que contient cette première maquette
- Tableau de bord et rubriques : agenda, courses, inventaire, recettes, tâches, routines, anniversaires.
- Ajout, coche et suppression d'éléments.
- Onglet Finances : budget mensuel, revenus, dépenses, catégories et bilan mensuel.
- Enregistrement local sur l'appareil utilisé.
- Fichiers de base pour l'installation PWA.

## Important
Cette version est un prototype : les données restent sur chaque appareil et ne sont PAS synchronisées entre appareils. La synchronisation en ligne nécessite de configurer un service de compte/base de données (par exemple Supabase) et d'héberger le site en HTTPS. Le manifeste n'inclut pas encore d'icônes personnalisées.

## Aperçu en local
Ouvrir `index.html` dans un navigateur. Pour tester l'installation PWA, il faut ensuite héberger le dossier sur un site HTTPS.

## Ajouter sur iPhone/iPad après hébergement
1. Ouvrir l'adresse du site dans Safari.
2. Appuyer sur Partager.
3. Choisir « Sur l'écran d'accueil ».
